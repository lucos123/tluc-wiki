# AI Engineering & Second Brain Operating Rules

1. **Strict Citation Discipline**: Every factual claim must be linked using Standard Relative Markdown Links (`[Page Name](relative/path.md)`).
2. **Zero Hallucination**: All model architectures, pricing, and benchmarks must be verified against official source documents in `raw/`.
3. **Synthesis & Compounding**: Always distill information over mere duplication. Preserve trade-offs, benchmarks, and evolving claims explicitly (`⚠️ Evolving claim`).
4. **Clean Categorization**: Route raw inputs to `raw/`, evergreen knowledge to `wiki/`, deliverables to `output/`, primitives to `ctx/`, and personal memory to `mem/`.
