# Multi-Source Synthesis Prompt Template

```markdown
Analyze and synthesize [Concept A](wiki/concepts/Concept%20A.md), [Concept B](wiki/concepts/Concept%20B.md), and [Entity C](wiki/entities/Entity%20C.md) into a structured evaluation:
1. Executive Thesis
2. Feature & Metric Comparison Matrix
3. Deep Architectural Trade-offs
4. Actionable Engineering Recommendations
```
