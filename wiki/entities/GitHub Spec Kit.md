# GitHub Spec Kit

**GitHub Spec Kit** is a mainstream software specification framework for AI coding agents (>121,000 GitHub stars, 35+ agent integrations).

Detailed in [Emerging Markdown Formats That Shape Coding Agent Behavior](../sources/Emerging%20Markdown%20Formats%20That%20Shape%20Coding%20Agent%20Behavior.md) by [Bilgin Ibryam](Bilgin%20Ibryam.md).

---

## Workflow Chain

```
spec.md (Requirements) ──> plan.md (Technical Design) ──> tasks.md (Executable Units) ──> Implementation & Validation
```

1. `spec.md`: Records business requirements and target outcome.
2. `plan.md`: Details technical architecture and implementation approach.
3. `tasks.md`: Breaks plan into executable work units for agents.

See [Metacode](../concepts/Metacode.md) and [Context Engineering](../concepts/Context%20Engineering.md).
