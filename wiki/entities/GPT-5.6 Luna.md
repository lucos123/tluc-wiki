# GPT-5.6 Luna

`gpt-5.6-luna` is the fast, cost-sensitive model tier in [[OpenAI]]'s [[GPT-5.6]] family.

## Specifications

- **Context & Output**: 1.05M context window, 128K max output tokens. Knowledge cutoff Feb 16, 2026.
- **Pricing**: $0.20 / 1M input, $0.02 / 1M cached input, $1.20 / 1M output tokens.
- **Role**: High-volume, repeatable tasks (classification, extraction, structured summaries, subagent worker nodes).

See [[GPT-5.6 Luna Model API Reference]] and [[GPT-5.6]].
