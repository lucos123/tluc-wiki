# Justin Schroeder

**Justin Schroeder** (`@jpschroeder`) is an open-source software engineer and founder/leader at [Standard Agents](Standard%20Agents.md) advocating for [Domain-Specific Agents](../concepts/Domain-Specific%20Agents.md), standardized portable agent harnesses, and non-public process-level agent evaluations.

---

## Key Contributions in Knowledge Base
- **[Why Domain-specific Agents Are the Future](../sources/Why%20Domain-specific%20Agents%20Are%20the%20Future.md)** (*AGNTCon + MCPCon North America / Agentic AI Foundation*, `2026-11-12`):
  - Introduced the **Line Shaft Era vs. Electric Motor** factory electrification analogy to critique monolithic generalist agent + skill setups.
  - Defined `Agent = Harness` ("deterministic software that utilizes non-deterministic results produced by a model in pursuit of a desired objective").
  - Built **Model Zen Garden** (inspired by CSS Zen Garden) to empirically demonstrate **jagged model capabilities** across niche tasks like 3D scene generation.
  - Outlined 5 open specification requirements for agent runtimes: Domain Specific, Full Harness, Portable, Vendor Agnostic (pinned provider/quantization), and Composable.
