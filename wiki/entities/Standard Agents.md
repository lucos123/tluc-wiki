# Standard Agents

**Standard Agents** is an AI engineering company led by [[Justin Schroeder]] building [[Domain-Specific Agents]] architectures, an open-source specification for portable agent harnesses, and competing runtime environments analogous to Node.js or Python for software packages.

---

## Architectural Vision & Roadmap
- **Open-Source Agent Specification:** Formalizing how narrow business-process agents bundle their complete harness (`Model + System Prompt + Tools + Hooks + Agent Rules`) so anyone can `npm install` or `pip install` a deterministic domain agent.
- **Portable Runtime & Governance:** Providing enterprise IT teams with visibility over fleets of small domain agents, process-specific non-public evals, and strict model/provider/quantization pinning so efficacy does not silently regress when upstream frontier models rotate.
