# AI Engineer

**AI Engineer** is a global community, technical conference series (AI Engineer World's Fair, AI Engineer Summit), and knowledge-sharing organization focused on the emerging discipline of AI engineering, agentic systems, LLMOps, and production AI architectures.

## Key Sources & Ingested Works

- [Why Your Enterprise Tech Stack Isn't Ready for AI Agents](../sources/Why%20Your%20Enterprise%20Tech%20Stack%20Isn%27t%20Ready%20for%20AI%20Agents.md): Technical presentation by Christopher Lovejoy and Saul Howard ([Anterior](Anterior.md)) on the 4 architectural primitives for enterprise agent stacks, the immutable action ledger, and Human-Agent Equivalency.
- [All Code Is Slop (Except Mine) — Lauren Tan, SpaceXSI](../sources/All%20Code%20Is%20Slop%20%28Except%20Mine%29%20%E2%80%94%20Lauren%20Tan%2C%20SpaceXSI.md): AI Engineer Code Summit presentation by [Lauren Tan](Lauren%20Tan.md) (`@poteto`, Principal Engineer at SpaceX / Grok Bot) introducing the [Poteto Trust Pyramid](../concepts/Poteto%20Trust%20Pyramid.md), deterministic lint-over-prose refactoring (`167` custom rules), runtime feature maps/CLIs, formal/UI verification (`TLA+`, `Lean`, `Bombadil`), and scaling to `11,000 PRs/month` at a `~0.5%` revert rate.
- [Rethinking Claude Code Best Practices — Lydia Hallie, Anthropic](../sources/Rethinking%20Claude%20Code%20Best%20Practices%20%E2%80%94%20Lydia%20Hallie%2C%20Anthropic.md): Late-2026 presentation by [Lydia Hallie](Lydia%20Hallie.md) on scaling [Claude Code](Claude%20Code.md) from `2,500` to `30,000+` daily changes via `/doctor prompt-audit`, plain-English `autoMode`, `/sandbox` & Cloud Sessions ([Cloud Agent Sandbox and Auto Mode](../concepts/Cloud%20Agent%20Sandbox%20and%20Auto%20Mode.md)), tri-stage `exit 2` verification hooks, risk-tiered CI auto-merge, and `Claude Code Projects` orchestration (`Fable` + `Opus 5.5`).
