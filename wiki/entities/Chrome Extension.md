# Chrome Extension

**Chrome Extension** (`Claude in Chrome`) is the official Chromium extension developed by [[Anthropic]] to enable deep browser automation, DOM inspection, live console log reading, and visual verification for [[Claude Code]].

---

## Technical Specifications

- **Extension ID**: `fcoeoabgfenejglbffodgkkbkcdhcgfn`
- **Supported Browsers**: Google Chrome, Microsoft Edge, Brave, Arc, Vivaldi, Opera.
- **Protocol**: Exposes browser control actions as native [[Model Context Protocol|MCP tools]] (`read_page`, `get_page_text`, `find`, `browser_batch`).

See [[Use Claude Code with Chrome]], [[Chrome Integration Architecture]], and [[Anthropic]].
