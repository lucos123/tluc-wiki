# Kyle Mistele

Kyle Mistele is an engineer and co-founder at [HumanLayer](HumanLayer.md), known for introducing Control Theory principles to agentic loop design.

## Key Contributions

- **Control-Loop Engineering**: Proposed applying classical control theory (Set Point, Sensor, Controller, Actuator, Disturbance Dampener) to agentic coding loops to avoid "blind Ralph loops" and unreviewable 40,000-line PRs.
- **Production Loop Patterns**: Introduced **Adaptive Flow Control** (pausing loop generation when unreviewed PRs are open) and **Human-on-the-Loop Resteering** using version-controlled `FEEDBACK.md` files updated via `/iterate` PR comments.

See [Loop Engineering from First Principles](../sources/Loop%20Engineering%20from%20First%20Principles.md) for details.
