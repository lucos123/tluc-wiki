# Viet Nguyen AI

**Việt Nguyễn AI** (`vietnh1009`) is a Vietnamese AI practitioner and technical content creator who curates, translates, and adapts visual guides and foundational AI/LLM engineering handbooks into Vietnamese for the developer and AI community.

---

## Key Contributions in Knowledge Base
- **[Prompt Engineering Handbook](../sources/Prompt%20Engineering%20Handbook.md)** (`2026-11-12`): Translated and adapted an 11-page visual sketchnote guide into Vietnamese covering prompt anatomy, prompting types (Zero-shot, One-shot, Few-shot, Role-based, Hybrid), frameworks (`CO-STAR`, `R-T-F`, `CLEAR`), reasoning patterns (`Chain-of-Thought`, `Self-Consistency`, `ReAct`, `Tree-of-Thought`, `Prompt Chaining`, `Meta-Prompting`), task templates, and pre-send checklists.
- **[Types of Machine Learning Handbook](../sources/Types%20of%20Machine%20Learning%20Handbook.md)** (`2026-11-16`): Translated and adapted a 13-page Vietnamese visual guide covering ML paradigms (Supervised, Unsupervised, Semi-Supervised, Self-Supervised, Reinforcement Learning), Regression/Classification/Clustering/Dimensionality Reduction algorithms, model evaluation metrics, and ML interview cheat sheets.
- **[AI Deployment Notes](../sources/AI%20Deployment%20Notes.md)** (`2026-11-15`): Translated and adapted a 12-page Vietnamese visual guide on AI Deployment covering the 7-stage AI/ML application lifecycle, Development vs. Deployment, Training vs. Inference, Dev/Staging/Prod environments, Model Packaging/Registry/Versioning, Batch vs. Real-Time, Online vs. Offline, Cloud vs. Edge, 6-layer architecture, and Inference Servers.
- **[LLM Handbook 50 Concepts](../sources/LLM%20Handbook%2050%20Concepts.md)** (`2026-11-11`): Translated and adapted a 20-page Vietnamese visual handbook covering 50 core LLM concepts from Transformers, tokenization/embeddings, pre-training scaling laws, LoRA/QLoRA fine-tuning, RLHF/DPO alignment, and RAG/Vector DBs through ReAct agents, benchmarks/hallucinations, quantization/KV Cache/vLLM serving, security guardrails, portfolio projects, and interview prep.
- **[Python Handbook](../sources/Python%20Handbook.md)** (`2026-11-17`): Compiled and shared a 10-page Vietnamese visual Python handbook covering language overview, variables/types, 7 operator families, I/O and conditionals, loops (`for`/`while`/`range`), functions (`DRY`, `lambda`, unpacking), strings, collections (`List`, `Tuple`, `Set`, `Dictionary`), and `with` file handling.
- **[AWS Core Services Notes](../sources/AWS%20Core%20Services%20Notes.md)** (`2026-11-16`): Translated and adapted an 18-page Vietnamese visual notebook summarizing 17 core [AWS](Amazon%20Web%20Services%20%28AWS%29.md) services (`Regions`, `IAM`, `EC2`, `EBS`, `VPC`, `ELB/ALB/NLB`, `Route 53`, `RDS`, `DynamoDB`, `SQS`, `ECS`, `EKS`, `ECR`, `CloudWatch`, `CloudTrail`, `Secrets Manager`, `KMS`) with diagrams, comparison tables, CLI snippets, and best practices.
- **[Machine Learning Basics Notes](../sources/Machine%20Learning%20Basics%20Notes.md)** (`2026-11-15`): Translated and adapted a 9-page Vietnamese handwritten visual notebook covering ML fundamentals, data taxonomies, 5-step Data Preprocessing, Feature Engineering, Overfitting/Underfitting diagnostics, Confusion Matrix, Cross-Validation, Hyperparameters, and the Python ML stack (`Scikit-learn`, `PyTorch`, `TensorFlow`, `Keras`, `Pandas`, `NumPy`).
- **[Computer Vision Handbook](../sources/Computer%20Vision%20Handbook.md)** (`2026-11-12`): Translated and adapted a 12-page Vietnamese handwritten visual cheatsheet covering pixels/RGB/tensors, Sobel edge/texture feature hierarchies, CNN convolution/stride/padding/backprop, image classification, object detection & YOLO (`IoU`, `NMS`), Semantic/Instance/Panoptic segmentation, Vision Transformers (`ViT`), `CLIP`, Multimodal fusion, and production Vision AI deployment.
- **[AI Complete Handbook](../sources/AI%20Complete%20Handbook.md)** (`2026-10-29`): Translated and adapted a 20-page comprehensive Vietnamese AI visual guide bridging Classical Symbolic AI (Intelligent Agents, `BFS`/`DFS`/`UCS`, Heuristic/`A*`, `Minimax`/Alpha-Beta, Knowledge Representation, First-Order Logic, Bayesian Inference) to Modern ML/DL, NLP/CV, GenAI/LLMs, Prompt Engineering, RAG/Vector DBs, AI Agents/Tool Calling, AI Evaluation/Safety/Ethics/Governance, and Deployment.
- **[AI Engineer Interview Notes](../sources/AI%20Engineer%20Interview%20Notes.md)** (`2026-10-30`): Curated and shared [Koteswara](Koteswara.md)'s 17-page production-first interview guide spanning LLM fundamentals, 6-step systematic prompt debugging, Hybrid RAG & `recall@k`/`faithfulness` evals, ReAct agent tool contracts, Fine-tuning vs. RAG vs. Prompting, LLM-Judge biases, 10M-user **AI System Design**, the business-impact Meta Pattern, and a 30-day prep checklist.
- **[25 HR Interview Questions in Vietnamese](../sources/25%20HR%20Interview%20Questions%20in%20Vietnamese.md)** (`2026-11-06`): Translated and shared an 8-page bilingual HR & behavioral interview guide featuring 25 common screening questions with fill-in-the-blank Vietnamese templates (`Q1–Q25`), Eisenhower task prioritization, 5 reverse interview questions, and 7 closing principles.
- **[AI Harness 6 Core Components](../sources/AI%20Harness%206%20Core%20Components.md)** (`2026-11-21`): Shared a concise visual breakdown of `Agent = Model + Harness` illustrating the 6 essential harness subsystems (*Agent Loop, Tool Calling, Context Management, Checkpointing, Permissions & Sandboxing, Guardrails*) through a customer order-support workflow.
- **[LLM Handwritten Study Guide 15 Pages](../sources/LLM%20Handwritten%20Study%20Guide%2015%20Pages.md)** (`2026-11-20`): Translated and adapted a 15-page formula-rich handwritten LLM notebook covering BPE/WordPiece/SentencePiece, sinusoidal positional encodings, LayerNorm/FFN math, attention $O(n^2 d)$ complexity, `SimHash`/`MinHash` dedup, `AdamW`/Cosine Annealing/`BF16`, `Houlsby`/`Pfeiffer`/`Compacter` adapters, decoding (`Beam Search`, `Repetition Penalty`), and the $\mathcal{L}_{\text{DPO}}$ equation.
