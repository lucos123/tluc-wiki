# Viet Nguyen AI

**Việt Nguyễn AI** (`vietnh1009`) is a Vietnamese AI practitioner and technical content creator who curates, translates, and adapts visual guides and foundational AI/LLM engineering handbooks into Vietnamese for the developer and AI community.

---

## Key Contributions in Knowledge Base
- **[[Prompt Engineering Handbook]]** (`2026-11-12`): Translated and adapted an 11-page visual sketchnote guide into Vietnamese covering prompt anatomy, prompting types (Zero-shot, One-shot, Few-shot, Role-based, Hybrid), frameworks (`CO-STAR`, `R-T-F`, `CLEAR`), reasoning patterns (`Chain-of-Thought`, `Self-Consistency`, `ReAct`, `Tree-of-Thought`, `Prompt Chaining`, `Meta-Prompting`), task templates, and pre-send checklists.
- **[[Types of Machine Learning Handbook]]** (`2026-11-16`): Translated and adapted a 13-page Vietnamese visual guide covering ML paradigms (Supervised, Unsupervised, Semi-Supervised, Self-Supervised, Reinforcement Learning), Regression/Classification/Clustering/Dimensionality Reduction algorithms, model evaluation metrics, and ML interview cheat sheets.
- **[[AI Deployment Notes]]** (`2026-11-15`): Translated and adapted a 12-page Vietnamese visual guide on AI Deployment covering the 7-stage AI/ML application lifecycle, Development vs. Deployment, Training vs. Inference, Dev/Staging/Prod environments, Model Packaging/Registry/Versioning, Batch vs. Real-Time, Online vs. Offline, Cloud vs. Edge, 6-layer architecture, and Inference Servers.
- **[[LLM Handbook 50 Concepts]]** (`2026-11-11`): Translated and adapted a 20-page Vietnamese visual handbook covering 50 core LLM concepts from Transformers, tokenization/embeddings, pre-training scaling laws, LoRA/QLoRA fine-tuning, RLHF/DPO alignment, and RAG/Vector DBs through ReAct agents, benchmarks/hallucinations, quantization/KV Cache/vLLM serving, security guardrails, portfolio projects, and interview prep.
- **[[Python Handbook]]** (`2026-11-17`): Compiled and shared a 10-page Vietnamese visual Python handbook covering language overview, variables/types, 7 operator families, I/O and conditionals, loops (`for`/`while`/`range`), functions (`DRY`, `lambda`, unpacking), strings, collections (`List`, `Tuple`, `Set`, `Dictionary`), and `with` file handling.
- **[[AWS Core Services Notes]]** (`2026-11-16`): Translated and adapted an 18-page Vietnamese visual notebook summarizing 17 core [[Amazon Web Services (AWS)|AWS]] services (`Regions`, `IAM`, `EC2`, `EBS`, `VPC`, `ELB/ALB/NLB`, `Route 53`, `RDS`, `DynamoDB`, `SQS`, `ECS`, `EKS`, `ECR`, `CloudWatch`, `CloudTrail`, `Secrets Manager`, `KMS`) with diagrams, comparison tables, CLI snippets, and best practices.
- **[[Machine Learning Basics Notes]]** (`2026-11-15`): Translated and adapted a 9-page Vietnamese handwritten visual notebook covering ML fundamentals, data taxonomies, 5-step Data Preprocessing, Feature Engineering, Overfitting/Underfitting diagnostics, Confusion Matrix, Cross-Validation, Hyperparameters, and the Python ML stack (`Scikit-learn`, `PyTorch`, `TensorFlow`, `Keras`, `Pandas`, `NumPy`).
- **[[Computer Vision Handbook]]** (`2026-11-12`): Translated and adapted a 12-page Vietnamese handwritten visual cheatsheet covering pixels/RGB/tensors, Sobel edge/texture feature hierarchies, CNN convolution/stride/padding/backprop, image classification, object detection & YOLO (`IoU`, `NMS`), Semantic/Instance/Panoptic segmentation, Vision Transformers (`ViT`), `CLIP`, Multimodal fusion, and production Vision AI deployment.
- **[[AI Complete Handbook]]** (`2026-10-29`): Translated and adapted a 20-page comprehensive Vietnamese AI visual guide bridging Classical Symbolic AI (Intelligent Agents, `BFS`/`DFS`/`UCS`, Heuristic/`A*`, `Minimax`/Alpha-Beta, Knowledge Representation, First-Order Logic, Bayesian Inference) to Modern ML/DL, NLP/CV, GenAI/LLMs, Prompt Engineering, RAG/Vector DBs, AI Agents/Tool Calling, AI Evaluation/Safety/Ethics/Governance, and Deployment.
- **[[AI Engineer Interview Notes]]** (`2026-10-30`): Curated and shared [[Koteswara]]'s 17-page production-first interview guide spanning LLM fundamentals, 6-step systematic prompt debugging, Hybrid RAG & `recall@k`/`faithfulness` evals, ReAct agent tool contracts, Fine-tuning vs. RAG vs. Prompting, LLM-Judge biases, 10M-user **AI System Design**, the business-impact Meta Pattern, and a 30-day prep checklist.
- **[[25 HR Interview Questions in Vietnamese]]** (`2026-11-06`): Translated and shared an 8-page bilingual HR & behavioral interview guide featuring 25 common screening questions with fill-in-the-blank Vietnamese templates (`Q1–Q25`), Eisenhower task prioritization, 5 reverse interview questions, and 7 closing principles.
