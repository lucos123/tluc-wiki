# Moonshot AI

Moonshot AI is an AI research lab known for developing the Kimi series of long-context, hyper-sparse MoE, and efficient frontier models.

## Model Progression & API Platform

- **API Endpoint**: Fully OpenAI SDK compatible via `https://api.moonshot.ai/v1`.
- **Flagship Lineup**:
  - [[Kimi K3]]: 2.8T parameter, 1M-context flagship model featuring [[Stable Latent MoE]] and Kimi Delta Attention (KDA).
  - [[Kimi K2.7 Code]]: Dedicated long-horizon coding model with 256K context and a HighSpeed variant (180–260 t/s).
  - `kimi-k2.6` & `kimi-k2.5`: Multimodal text, image, video, and agentic reasoning models.
- **Innovation Focus**: Pushing the boundaries of open-source model scale, sub-quadratic linear attention, and ultra-sparse MoE inference economics.

See [[Kimi K3 Model Guide]], [[Kimi K2.7 Code Guide]], [[Kimi API Model List & Deprecations]], and [[Kimi API Quickstart & Integration]].
