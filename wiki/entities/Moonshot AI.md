# Moonshot AI

Moonshot AI is an AI research lab known for developing the Kimi series of long-context, hyper-sparse MoE, and efficient frontier models.

## Model Progression & API Platform

- **API Endpoint**: Fully OpenAI SDK compatible via `https://api.moonshot.ai/v1`.
- **Flagship Lineup**:
  - [Kimi K3](Kimi%20K3.md): 2.8T parameter, 1M-context flagship model featuring [Stable Latent MoE](../concepts/Stable%20Latent%20MoE.md) and Kimi Delta Attention (KDA).
  - [Kimi K2.7 Code](Kimi%20K2.7%20Code.md): Dedicated long-horizon coding model with 256K context and a HighSpeed variant (180–260 t/s).
  - `kimi-k2.6` & `kimi-k2.5`: Multimodal text, image, video, and agentic reasoning models.
- **Innovation Focus**: Pushing the boundaries of open-source model scale, sub-quadratic linear attention, and ultra-sparse MoE inference economics.

See [Kimi K3 Model Guide](../sources/Kimi%20K3%20Model%20Guide.md), [Kimi K2.7 Code Guide](../sources/Kimi%20K2.7%20Code%20Guide.md), [Kimi API Model List & Deprecations](../sources/Kimi%20API%20Model%20List%20%26%20Deprecations.md), and [Kimi API Quickstart & Integration](../sources/Kimi%20API%20Quickstart%20%26%20Integration.md).
