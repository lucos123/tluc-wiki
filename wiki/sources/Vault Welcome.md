# Vault Welcome

This is a summary of the default onboarding note provided by Obsidian when creating a new vault. 

It recommends starting by:
1. Making notes and creating links to build out the knowledge graph.
2. Using the Importer plugin to bring in data from other sources.
3. Deleting the onboarding note once the user is ready to make the vault their own.
