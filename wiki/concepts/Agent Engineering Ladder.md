# Agent Engineering Ladder

The **Agent Engineering Ladder** is the 5-stage evolutionary hierarchy of AI agent design paradigms detailed by [Sean's AI Stories](../entities/Sean%27s%20AI%20Stories.md) in [You Can Learn AI Agent Graph Engineering In 21 Min](../sources/You%20Can%20Learn%20AI%20Agent%20Graph%20Engineering%20In%2021%20Min.md).

---

## The 5 Evolutionary Rungs

```
Prompt Engineering (Role-Playing: "act as Shakespeare")
  └── Context Engineering (Feeding CRM & RAG data into prompts)
        └── Skills (Procedural memory & SKILL.md playbooks)
              └── Loop Engineering (Goal-driven tool exploration: "go figure it out")
                    └── Graph Engineering (Controlled SOPs + Exploratory Sub-Loops)
```

1. **[Prompt Engineering](Prompt%20Engineering.md)**: Early role-playing, structured prompt anatomy, few-shot examples, and CoT tuning.
2. **Context Engineering**: Structuring data, RAG payloads, and CRM context.
3. **Skills**: Encapsulating procedural memory into repeatable task playbooks.
4. **Loop Engineering**: Autonomous, goal-driven tool iterations.
5. **Graph Engineering**: Orchestrating multi-agent networks, combining deterministic SOPs with internal goal loops.

See [Prompt Engineering](Prompt%20Engineering.md), [Graph Engineering](Graph%20Engineering.md), [Loop Engineering](Loop%20Engineering.md), and [Context Engineering](Context%20Engineering.md).
