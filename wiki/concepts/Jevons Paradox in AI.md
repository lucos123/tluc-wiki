# Jevons' Paradox in AI

**Jevons' Paradox in AI** describes the economic phenomenon where falling per-token base model inference costs lead to an exponential increase in total AI token consumption across the software industry.

---

## Economic Mechanism

```
  Falling Model Price ($-70% per token)
             │
             ▼
  Increased Harness Density & Capability (Thick System Prompts, 30K Tokens/Turn)
             │
             ▼
  Developer Migration from Single-Turn Chat → Autonomous Agentic Loops
             │
             ▼
  Net Increase in Total Token Spend per Developer ($150 - $250 / month)
```

As models (e.g. GPT-5.6 Sol, Kimi K3) become cheaper and faster, developers shift from single-turn chat completion interfaces to **thick agentic harnesses** ([[Claude Code]], Cursor, [[Cline]]) that consume 4× to 15× more tokens per task via system prompt tollgates and recursive tool execution loops.
