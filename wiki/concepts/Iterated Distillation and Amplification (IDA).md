# Iterated Distillation and Amplification (IDA)

A training methodology heavily leveraged by [[OpenBrain]] in the [[AI 2027]] scenario to achieve superhuman coding capabilities with [[Agent-3]].

**Process**:
1. **Amplification**: Spend more resources (compute, time, parallel copies) to improve a model's performance on a task, creating an "amplified" system that produces high-quality outputs.
2. **Distillation**: Train a new, more efficient model to imitate the outputs of the amplified system using less compute.
