# The Factory Model

A mental model for modern software engineering described in [The New SDLC With Vibe Coding](../sources/The%20New%20SDLC%20With%20Vibe%20Coding.md).

## Concept
In the AI era, the developer's primary output is no longer code. Instead, the developer builds and designs the *system* (the factory) that produces the code. 

## The Factory Includes:
- **Specifications & Context**: Defining what needs to be built.
- **Agents**: The workers translating specs into implementation.
- **Tests & Quality Gates**: Ensuring the output is correct.
- **Feedback Loops**: Routing failures back to the agents for correction.
- **Guardrails**: Constraining agents to safe behavior.
