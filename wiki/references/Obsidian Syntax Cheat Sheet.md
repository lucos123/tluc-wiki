# Obsidian Syntax Cheat Sheet

Quick reference guide for markdown syntax used in `tluc-wiki`.

## Wiki Links
- Internal Page Link: `Page Title` surrounded by double brackets
- Display Alias Link: `Page Title|Custom Text` surrounded by double brackets
- Heading Link: `Page Title#Section Heading` surrounded by double brackets

## Callouts & Alerts
- Note: `> [!NOTE]`
- Important: `> [!IMPORTANT]`
- Warning: `> [!WARNING]`
- Tip: `> [!TIP]`
